# Hikari Companion

> 由你定义形象与人格、由社区不断扩展能力的开源桌面 AI 伙伴。

[English](./README.en.md) · [路线图](./ROADMAP.md) · [参与贡献](./CONTRIBUTING.md) · [架构说明](./docs/architecture.md)

Hikari 不是一个预设角色，而是一个让每个人创造自己专属助手的平台。你可以上传形象、设定人格与关系、选择在线或本地模型，再通过文字和语音与它交流。长期目标是让它逐步拥有记忆、屏幕感知、工具调用和跨设备协作能力，成长为真正属于用户的个人智能体。

## 当前状态

项目处于 **v0.1 原型阶段**。当前代码已经提供：

- Windows 桌面应用基础框架
- 首次启动角色创建向导
- PNG、JPG、WebP 形象上传与本地保存
- 自定义名字、人格、背景和关系
- 文字聊天与系统语音朗读
- 浏览器/系统支持时的语音输入
- 演示模式以及 OpenAI 兼容的在线、本地模型接口
- 可查看、添加、删除的本地长期记忆
- 普通窗口与透明桌面伙伴模式
- 危险操作必须确认的权限设计基础
- Windows 安装包构建配置

Live2D、VRM、自动记忆总结、屏幕感知和工具插件尚未完成，欢迎参与路线图中的里程碑。

## 快速开始

需要 Node.js 24+ 与 pnpm 11+。

```bash
pnpm install
pnpm dev
```

只在浏览器预览界面：

```bash
pnpm dev:web
```

检查代码：

```bash
pnpm typecheck
pnpm test
pnpm build
```

构建 Windows 安装包：

```bash
pnpm dist:win
```

## 连接模型

Hikari 使用 OpenAI 兼容的 `/chat/completions` 接口，项目本身不绑定具体模型厂商。

1. 在首次启动向导或“设置”中选择在线模型或本地模型。
2. 填写兼容接口的基础地址和服务商支持的模型名称。
3. 在线服务通常需要 API 密钥；本地服务可能不需要。

API 密钥通过 Electron 的系统安全存储能力加密后保存在本机，不会写入项目文件。请勿将密钥提交到 GitHub。

## 产品原则

1. **角色属于用户**：项目不强制固定性别、形象、声音或关系。
2. **本地优先**：角色资料和记忆默认留在用户的设备上。
3. **模型可替换**：在线服务、本地模型和未来的新模型使用统一接口。
4. **能力需授权**：删除、付款、发布、账号和权限操作必须明确确认。
5. **开放扩展**：形象、语音、记忆、模型和工具最终都通过插件扩展。

## 参与贡献

这是一个希望由社区共同成长的长期项目。无论你擅长前端、AI、Live2D、3D、语音、设计、测试还是文档，都能找到可以参与的方向。请先阅读 [CONTRIBUTING.md](./CONTRIBUTING.md)，也可以从 [首批任务](./docs/initial-issues.md) 中选择一个小目标。

## 安全与边界

Hikari 未来可能获得操作电脑的能力，因此权限系统不是可选功能。任何插件和自动化能力都必须遵守最小权限、操作可见、危险操作确认、可随时撤销的原则。安全问题请按照 [SECURITY.md](./SECURITY.md) 私下报告。
