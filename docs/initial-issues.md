# 首批 GitHub Issues

仓库公开后，可以按照以下顺序创建任务。每项已经写成可直接复制到 GitHub 的任务说明。

## 1. 建立 Live2D AvatarAdapter 接口

**Labels:** `feature`, `avatar`, `architecture`

定义角色渲染适配器的最小生命周期，避免 UI 与某个形象 SDK 绑定。

**验收标准：**

- 提供 `load`、`setExpression`、`setLipSync`、`dispose` 接口。
- 静态图片通过同一接口运行。
- 添加接口单元测试与一份示例适配器文档。
- 不把第三方闭源 SDK 代码提交到仓库。

## 2. 支持拖放导入透明 PNG

**Labels:** `good first issue`, `feature`, `ui`

角色工作室目前使用文件选择器，增加拖放区域和明确的错误反馈。

**验收标准：**

- 支持 PNG/JPG/WebP 拖放。
- 校验文件类型与 5 MB 限制。
- 拖放时有可见状态，键盘用户仍可完成导入。

## 3. 将记忆持久化迁移到 SQLite

**Labels:** `feature`, `memory`, `data`

为自动总结和检索准备结构化存储，并提供从当前 JSON 状态迁移的方法。

**验收标准：**

- 定义记忆、来源、时间和用户编辑状态字段。
- 首次升级自动迁移，不丢失已有数据。
- 支持导出和彻底删除。
- 包含数据库迁移测试。

## 4. 实现候选记忆审核队列

**Labels:** `feature`, `memory`, `privacy`

模型可以建议长期记忆，但未经用户允许不能直接永久保存敏感内容。

**验收标准：**

- 区分“候选”和“已确认”记忆。
- 用户可接受、编辑或拒绝。
- 提供自动接受开关，并清楚说明隐私影响。

## 5. 增加模型连接测试按钮

**Labels:** `good first issue`, `feature`, `model-provider`

在设置页验证地址、鉴权和模型名称，并返回可理解的诊断结果。

**验收标准：**

- 不在错误信息或日志中显示密钥。
- 区分网络、鉴权、模型不存在和响应格式错误。
- 成功后显示延迟和服务类型。

## 6. 支持流式回复和中止生成

**Labels:** `feature`, `chat`, `model-provider`

使用兼容的流式接口逐步显示回复，并提供停止按钮。

**验收标准：**

- 渲染进程通过受限 IPC 接收数据块。
- 切换页面或点击停止会取消请求。
- 部分回复不会被错误写入长期记忆。

## 7. 设计权限清单与确认对话框

**Labels:** `security`, `architecture`, `ux`

实现 `observe`、`act`、`dangerous` 三类权限的声明与用户确认原型。

**验收标准：**

- 危险操作不能选择“永远允许”。
- 对话框显示动作、目标、发起插件和可见后果。
- 拒绝后不会执行任何副作用。
- 添加绕过确认的回归测试。

## 8. 改善中文语音选择

**Labels:** `good first issue`, `voice`, `accessibility`

允许用户从系统语音列表中选择声音、语速和音调，并提供试听。

**验收标准：**

- 保存语音 ID 而不是不稳定的数组序号。
- 语音不存在时安全回退。
- 支持关闭自动朗读。

## 9. 建立角色包 JSON Schema

**Labels:** `avatar`, `spec`, `help wanted`

把架构文档中的草案发展为版本化 Schema 和验证器。

**验收标准：**

- 校验角色 ID、版本、形象入口和许可证信息。
- 拒绝越过角色包根目录的路径。
- 提供合法与恶意示例测试包。

## 10. Windows 安装包与发布流水线

**Labels:** `ci`, `release`, `windows`

构建可重复的 Windows 安装包，并为后续签名保留安全位置。

**验收标准：**

- Tag 推送时生成 NSIS 安装包和校验值。
- PR 只进行构建验证，不发布。
- 构建产物不包含开发密钥或用户数据。
- README 记录安装与卸载方式。
